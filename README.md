# evolution · Web 鱼群水族馆

`experiment` 分支是纯 Vite + Three.js Web 版本。同一页面提供两套隔离体验：

- **Game 模式**面向玩家，用三个参数完成三代生存实验。
- **实验调试模式**面向开发者，包含主水族馆、地图刚体和生态淘汰。

默认入口仍是持续运行的主水族馆。切换模式不会把调试面板暴露给 Game 玩家。

## 本地运行

```bash
npm install
npm run dev
```

Vite 会打印局域网访问地址。手机和桌面浏览器都直接打开这个地址，不需要
Electron、Tauri、Godot 或其他套壳。

## 验证生产版本

```bash
npm test
npm run test:balance
npm run build
npm run preview
```

`npm test` 是快速逻辑回归；`npm run test:balance` 会用五个固定种子验证三代
推荐路线，并要求同一继承底本下的中心点与指定错误选择全部失败。生产预览
还需要确认 Rapier WASM 正常加载。目标浏览器为最新版 Chromium、Safari 与
Firefox。

## Game 模式

在项目切换器中选择 **进化游戏**。玩家只会看到关卡信息、一个三角形控制器、
蓝鱼存活率、倒计时和结算；完整实验参数盘会隐藏。

三角形的三个方向分别代表 **速度、体型、耐力**。拖动其中的点会生成本代
三项乘法系数；中心点表示三项均为 `×1`。任一顶点会把对应方向推到 `×1.5`，
同时把另外两项降到 `×0.5`。不会把完整实验参数直接交给玩家。

三角位置使用三项和为 `1` 的重心权重。每个方向的权重 `w` 都按同一公式
转成倍率：

```text
w ≤ 1/3：m = 0.5 + 1.5w
w ≥ 1/3：m = 0.75 + 0.75w
```

每关只有开局可以调参。点击开始后，本关参数立即锁定：

```text
TUNING 调参 → RUNNING 演算 → VERDICT 结算
                         成功 → INHERIT 封代 → 下一关 TUNING
                         失败 → 保留参数并重建本关 → TUNING
```

成功关卡会把本代三项系数写入代际记录，并与已有累计系数逐项相乘。下一代
实际表型始终按“理想基础参数 × 累计系数”重算，并从中心点获得一次新的
三角形调整机会。累计值不截断，因此同一轴先 `×1.5`、再 `×0.5` 会得到
`×0.75`。失败不会形成新一代，也不会改变累计系数；重试保留失败时的控制点
作为调整起点。后两关失败时也可以显式重开整条谱系。继承的是参数，不是
上一关的活鱼、当前能量或存活数量。

关卡文字提供方向而不设置隐藏答案；实际胜负只看公开的存活率。较早一代的
体型或耐力投资如果让后代少调整也能过关，这是乘法继承允许的跨代策略。
每次进入关卡、重试或重新实验都会随机生成三群鱼的新出生布局；调参画面到
点击开始复用同一个布局，不会在确认的一刻突然重排。

| 关卡 | 环境与引导 | 时长 | 蓝鱼获胜线 |
| --- | --- | ---: | ---: |
| L1 · 匮乏年代 | 捕食者存在，食物勉强充饥；倾向适度减小体型、增加耐力或速度 | 90 秒 | 35% |
| L2 · 黄金时代 | 浮游不足、捕食者很少；增大体型以捕食原本平行的鱼群 | 75 秒 | 75% |
| L3 · 后疫情时代 | 食物与捕食者都少、活动降低；倾向增加耐力 | 105 秒 | 50% |

Game 模式不繁殖、不自动补鱼，也不写入 `localStorage`。刷新页面会清空进度，
恢复单位累计系数，并回到 L1 的三角形中心点。第三关成功后显示三代汇总；
**重新实验**执行同样的完整重置。

## 实验调试模式

下列项目没有关卡、轮次或代际继承。这里的“无关卡/无轮次”只描述实验调试
模式，不适用于上面的独立 Game 模式。

- **主水族馆**：体型关系动态推导。拖动任一鱼群的 `size` 会立即重算全部
  角色。死亡永久减少当前数量，reset/rebuild 才恢复初始种群。
- **地图与水中刚体**：启用穿孔障碍、距离场和 Rapier 动态物体。
- **生态淘汰**：浮游资源按 logistic 方程生长并被消耗；鱼会捕食补能或
  因能量归零死亡。唯一幸存种群获胜，全部灭绝记为 collapse。

## 观察与调参

- 单击鱼后，相机拉近并持续跟随。
- 单击活鱼会在左下角打开实时第三人称观察窗，可选择“特写视角”或“跟随
  视角”全屏；两种全屏状态都使用 ESC 返回全局。
- 吃掉一条鱼时会显示碎片爆发与咬合闪光；全部特效参数均可调整。
- 所有项目都没有固定补鱼机制；死亡个体不会按目标数量返回。
- 每条捕食关系显示追击次数、真实捕获、转化率、平均追击时长和名义闭合
  时间，`burstFactor=1.35` 保留为可调默认值。
- **鱼群**编辑器使用前后箭头切换当前鱼群，并支持复制新增或删除。
  体型、数量、颜色、运动、群游、浮游摄食率和出生布局都收在当前鱼群内部。
  Separation、Alignment、Cohesion 各自把实际 radius、半径控制项与当前
  鱼群 weight 放在同一栏；radius 决定“看见谁”，weight 决定“反应多强”。
- `wall margin` 是鱼心不能越过的硬边界内缩；`edge softness` 是靠近缸壁
  和静态障碍时逐渐增强转向的软缓冲带。
- `cross separation` 是不同鱼群之间按较大鱼体型缩放的连续斥力，不是
  捕食感知范围；同群 cohesion 只响应其局部半径内的邻居，不再有指向全群
  群心的隐藏兜底力。
- `population preset` 可在完整 `400/200/80` 与性能 `200/80/40` 间切换；
  手动修改数量后自动标为自定义。
- 数值标签旁的 `+ / −` 可围绕当前值缩小或扩大调试量程，`↺` 同时恢复
  默认值与完整安全量程；切换鱼群或重建面板不会丢失当前量程窗口。
- 时间快捷键：按住 Enter 临时使用 `2×`，按住 Space 临时使用 `0.2×`；
  松开恢复 `1×`，200ms 内连续按两次 Space 回到全局原视角；窗口失焦也会
  自动恢复。输入面板时快捷键不会触发。
- 捕食者只有在局部 hunt radius 内才施加捕猎凝聚，猎物也只有在局部 panic
  radius 内逃逸；范围外完全按普通 Boid 游动，不再追逐猎物鱼群的全局群心。
- 控制台可通过 `window.experiment` 重置、导入配置、读取指标、切换项目
  或生成动态刚体。

实验与调试层的完整参数表可由下列命令重新生成：

```bash
node tools/export_experiment_parameters.mjs --write
```

生成结果见 [docs/EXPERIMENT_PARAMETERS.md](./docs/EXPERIMENT_PARAMETERS.md)。
Game 玩家不会直接看到这张完整参数表。
